# Сбор данных через API и веб-скрейпинг на Python

Учебный проект, посвящённый двум способам сбора данных: получению информации о вакансиях через API портала «Работа России» и сбору данных о товарах с сайта интернет-магазина «Детский мир».

## О проекте

Проект состоит из двух независимых частей.

### 1. Сбор данных о вакансиях через API trudvsem.ru

Получение данных о вакансиях с использованием открытого API портала [«Работа России»](https://trudvsem.ru/).

**Выполненные задачи:**
- Изучение структуры и возможностей API.
- Отправка GET-запросов и обработка ответов в формате JSON.
- Реализация постраничной загрузки данных.
- Извлечение основных характеристик вакансий: название должности, регион, работодатель, заработная плата, тип занятости и график работы.
- Сохранение собранных данных в CSV-файл.
- Проверка данных на дубликаты.

**Результат:** собрано 9 780 уникальных вакансий после удаления дубликатов.

### 2. Веб-скрейпинг интернет-магазина «Детский мир»

Сбор информации о товарах из каталога [«Детский мир»](https://www.detmir.ru/catalog/index/name/sport_otdyh/).

**Выполненные задачи:**
- Отправка HTTP-запросов и получение HTML-страниц.
- Парсинг HTML с помощью BeautifulSoup.
- Извлечение названий товаров, цен, рейтингов, кодов товаров и артикулов.
- Переход по страницам каталога и сбор данных о товарах.
- Получение дополнительной информации со страниц отдельных товаров.
- Формирование DataFrame с помощью Pandas.
- Проверка качества собранных данных.
- Сохранение результатов в CSV-файл.

**Результат:** собрано 105 записей о товарах с трёх страниц каталога.
